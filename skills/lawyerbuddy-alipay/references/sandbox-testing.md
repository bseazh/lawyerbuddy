# 沙箱测试

真实支付宝沙箱测试前需要：沙箱 App ID、应用私钥、支付宝公钥、可访问回调地址和明确的业务接口。缺少任一项时停止在配置检查，不索要或生成生产私钥。

## 验收清单

1. 无 Payment-Proof：返回 402，授权令牌尚未签发。
2. 无效或过期凭证：拒绝交付并记录原因。
3. 有效凭证：订单金额必须为 0.01 元，然后交付资源。
4. 成功交付：写入订单号、资源标识、时间和履约状态。
5. 同一订单重试：返回相同资源和回执，不重复扣费。
6. 生成失败：不得写入成功履约状态，可安全重试。

测试报告要列出场景、请求、响应状态、订单号、授权编号、履约状态和待确认项。本地模拟通过不代表支付宝真实扣款成功。
